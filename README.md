# VivanceData community files

The shared files for the [VivanceData](https://github.com/Vivancedata)
organisation: the profile shown on the organisation page, the default code of
conduct, security policy and pull request template, and the brand kit.

VivanceData is Lorenzo Scaturchio's one-person practice. I build small,
specific AI systems for trade and field businesses and stay on to keep them
running. See the [organisation profile](profile/README.md) for what lives here.

- [`profile/README.md`](profile/README.md): the organisation page
- [`BRAND.md`](BRAND.md): the mark, colours, type, rendered assets and LinkedIn copy
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`SECURITY.md`](SECURITY.md),
  [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md): defaults for every repository
